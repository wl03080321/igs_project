# 爬蟲配置使用說明

## 配置文件：config.json

現在所有的設定都在 `config.json` 文件中，包括爬蟲參數和 API 配置。

### 配置說明：

```json
{
  "api_token": "",                           // 通用 API 認證令牌（如果需要的話）
  "date_after": "2025-07-01T00:00:00",      // 開始時間
  "date_before": "2025-07-01T23:59:59",     // 結束時間
  "data_root": "./data",                     // 數據存放目錄
  "per_page": 100,                          // 每頁抓取數量
  "websites": [                             // 目標網站列表
    "https://www.igamingbusiness.com/",
    "https://cdcgaming.com/"
  ],
  "keywords": {                             // 關鍵字分類
    "實體賭場": ["Casino"],
    "線上博弈": ["mobile+Gambling"],
    "社交博弈": ["social+casino"],
    "法規與政策": ["Market+Trends", "Regulatory", "policy", "class+action", "lawsuit", "state+prohibition", "state+ban"],
    "平台": ["App+Store", "Google+Play"]
  },
  "openai": {                               // OpenAI API 設定
    "api_key": "your_openai_api_key_here",
    "model": "gpt-4o",
    "max_tokens": 300,
    "temperature": 0.7
  },
  "mongodb": {                              // MongoDB 連接設定
    "uri": "your_mongodb_connection_string",
    "database": "igs_project",
    "collection": "insight_report"
  },
  "analysis": {                             // 分析設定
    "rate_limit_delay": 1,                  // API 請求間隔（秒）
    "tags": ["市場", "法規", "政策", "集體訴訟", "訴訟", "州禁令"]
  }
}
```

### 常見修改範例：

#### 1. 修改時間範圍（爬取昨天的新聞）
```json
"date_after": "2025-08-05T00:00:00",
"date_before": "2025-08-05T23:59:59"
```

#### 2. 修改 OpenAI API 設定
```json
"openai": {
  "api_key": "sk-your-actual-api-key",
  "model": "gpt-4",
  "max_tokens": 500,
  "temperature": 0.5
}
```

#### 3. 修改 MongoDB 連接
```json
"mongodb": {
  "uri": "mongodb://localhost:27017/",
  "database": "my_database",
  "collection": "my_collection"
}
```

#### 4. 增加新的分析標籤
```json
"analysis": {
  "rate_limit_delay": 2,
  "tags": ["市場", "法規", "政策", "集體訴訟", "訴訟", "州禁令", "新標籤"]
}
```

#### 5. 增加新的關鍵字分類
```json
"keywords": {
  "實體賭場": ["Casino"],
  "線上博弈": ["mobile+Gambling"],
  "社交博弈": ["social+casino"],
  "法規與政策": ["Market+Trends", "Regulatory", "policy", "class+action", "lawsuit", "state+prohibition", "state+ban"],
  "平台": ["App+Store", "Google+Play"],
  "新分類": ["新關鍵字1", "新關鍵字2"]
}
```

### 使用的程序：

#### 1. 爬取新聞：
```bash
python main_week.py
```

#### 2. 分析新聞：
```bash
python analyze_files_week.py
```

### 注意事項：
- 如果 config.json 不存在，程序會使用預設值
- 請妥善保管 API 金鑰，避免洩露
- 修改配置後直接運行程序即可
- JSON 格式要正確，注意逗號和引號
- OpenAI API 需要有效的金鑰才能使用
- MongoDB 需要有效的連接字串才能儲存結果
